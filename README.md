# Berg (Arena Survival)

A fast-paced 2D arcade action-platformer built with Python and Pygame.
You play as Berg, an Ice Golem, surviving 12 waves of prehistoric beasts in a single, intense arena.

## Features
- **Aggressive Combat Loop:** Melee kills generate "Ice Mana", which can be spent on ranged attacks and defensive ice blocks.
- **Retro Aesthetics:** Native 120x90 pixel resolution scaled up for modern screens.
- **Strict Palette:** Limited to a pure 27-color RGB palette (values 0, 127, 255).
- **Dynamic Atmosphere:** The weather and time of day worsen as you progress through the 12 waves, ending in a pitch-black blizzard.

## Tech Stack
- Python 3
- Pygame
